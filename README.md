# Professional ICT Portfolio

Open `index.html` in a browser to preview the website.

## Customize
1. Replace the `YOUR PHOTO` placeholder with your professional photo.
2. Update the name `MARK` in `index.html`.
3. Replace `your.email@example.com`.
4. Add your LinkedIn and GitHub URLs.
5. Replace or expand project descriptions.
6. Connect the contact form to Formspree, EmailJS, a backend API, or your preferred email service before production.

The site is plain HTML/CSS/JavaScript so it can be hosted on GitHub Pages, Netlify, Vercel, shared hosting, or any web server.
